# 리뷰답글 도우미

배달앱·지도앱 리뷰를 붙여넣으면 **가게 말투에 맞춘 답글 초안**을 만들어 주고, 사장님은 확인만 하고 올리는 도구입니다.
「삶의 질 개선 아이디어 10. 소상공인 리뷰 답글 마이크로 SaaS」를 그대로 구현한 첫 버전입니다.

| 요구사항 | 구현 방식 |
| --- | --- |
| 리뷰 입력 → 별점·내용에 맞춘 답글 초안 → 승인하면 게시 | 리뷰 붙여넣기 → 초안 3종(기본/짧게/정성 가득) → **승인하고 복사** → 사장님 센터 열기 → **게시 완료** 표시 |
| 악성 리뷰는 감정적이지 않은 대응 문구 따로 제안 | 욕설·별점 압박·근거 없는 최저점 감지 → 차분한 대응 문구 + "사장님이 하실 일"(신고·증빙 보관) |
| 다시 설치하지 않고 업데이터로 개선 | PC 실행본은 실행할 때마다 자동 업데이트 + 앱 안의 **지금 업데이트** 버튼, 웹앱·휴대폰 앱은 서버 갱신 시 "새 버전이 준비됐어요 → 지금 적용" |
| 아이콘 두 번 클릭으로 실행 | 설치 스크립트가 바탕화면에 **리뷰답글 도우미** 아이콘을 만듦 (Windows / macOS / Linux) |
| 모바일 폰에서도 실행 | 반응형 웹앱(PWA) — 휴대폰 홈 화면에 앱으로 설치 |
| 같은 계정이면 폰과 PC 연동 | 모든 데이터는 계정 단위로 서버에 저장, 실시간 스트림으로 다른 기기 화면이 즉시 갱신 |
| 최종적으로 모바일 앱 배포·수익화 | 무료 체험 → 무료(월 10회) → 프로(월 9,900원) 요금제, 관리자 화면, Capacitor 스토어 앱 껍데기 (`mobile/`) |

---

## 1. PC 에 설치하고 아이콘으로 실행하기

**준비물:** [Node.js](https://nodejs.org/ko/download) LTS 버전(22.13 이상). 설치 스크립트가 없으면 다운로드 페이지를 열어 줍니다.

1. 이 저장소를 받습니다. (자동 업데이트를 위해 `git clone` 을 권장합니다)
   ```bash
   git clone https://github.com/tlsgusdlf33/A14.git 리뷰답글도우미
   ```
2. 폴더 안의 설치 파일을 **두 번 클릭**합니다.
   - Windows: `INSTALL-Windows.bat`
   - macOS: `INSTALL-Mac.command` (처음 한 번은 우클릭 → 열기)
   - Linux: `INSTALL-Linux.sh`
3. 바탕화면에 생긴 **리뷰답글 도우미** 아이콘을 두 번 클릭하면 앱 창이 열립니다.
   - 아이콘을 누를 때마다: 새 버전 확인 → 서버 실행(이미 켜져 있으면 생략) → 주소창 없는 앱 창 열기
   - 서버 끄기: Windows `launcher/stop-windows.bat`, 그 외 `node scripts/launch.js --stop`
4. 처음 화면에서 **무료로 시작하기**로 가입 → **가게 설정**에서 가게 이름·말투를 입력합니다.

> AI 답글을 쓰려면 폴더의 `.env` 파일에 `ANTHROPIC_API_KEY` 를 넣으세요. 비워 두면 **내장 문장 엔진**(규칙 기반, 무료)으로 동작하므로 키 없이도 바로 써 볼 수 있습니다.

## 2. 휴대폰에서 쓰기 · PC 와 연동

- **같은 와이파이(PC 가 서버일 때):** 서버 창이나 앱의 **내 정보 → 휴대폰에서 쓰기**에 나오는 `http://192.168.x.x:8787` 주소를 휴대폰 브라우저로 열고 같은 계정으로 로그인합니다.
- **어디서나(권장):** 서버를 클라우드에 올리면(아래 4번) 휴대폰·PC 모두 `https://내도메인` 으로 접속합니다. HTTPS 에서는 휴대폰 홈 화면에 **앱으로 설치**되고 오프라인에서도 화면이 열립니다.
- 같은 계정으로 로그인한 기기끼리는 리뷰·답글 수정·승인 상태·가게 설정이 **실시간으로 연동**됩니다.
  예) PC 에서 리뷰를 넣고 승인 → 휴대폰 리뷰함에 바로 "승인됨" 표시 → 휴대폰에서 "게시 완료" → PC 화면도 즉시 갱신.
- **내 정보 → 로그인한 기기**에서 기기 목록을 보고 다른 기기를 원격 로그아웃할 수 있습니다.

## 3. 업데이트 (다시 설치하지 않음)

| 실행 형태 | 업데이트 방법 |
| --- | --- |
| PC 실행본 (git 으로 받음) | 아이콘을 누를 때마다 `git fetch` 로 새 버전을 확인해 자동 적용. 실행 중이면 관리자에게 상단 배너 + **내 정보 → 지금 업데이트** 버튼 (적용 후 서버가 스스로 재시작) |
| PC 실행본 (압축 파일로 받음) | `.env` 의 `UPDATE_MANIFEST_URL` 에 `update-manifest.json` 주소를 적으면 그 버전 정보를 보고 새 압축본을 받아 덮어씀. `data/` 와 `.env` 는 보존 |
| 웹앱 / 휴대폰 앱 | 서버가 새 버전이 되면 열려 있는 모든 기기에 "새 버전이 준비됐어요 → 지금 적용" 배너. 누르면 즉시 새 화면으로 전환 |
| 스토어 앱 (Capacitor) | 화면을 서버에서 불러오므로 서버만 업데이트하면 앱 재배포 없이 반영 |

새 버전을 내는 방법: `package.json` 의 `version` 과 `update-manifest.json` 의 `version` 을 올려서 커밋·push 하면 됩니다. 데이터베이스 구조 변경은 `server/db.js` 의 `MIGRATIONS` 에 **추가만** 하면 기존 데이터를 유지한 채 자동 적용됩니다.

## 4. 클라우드에 올리기 (PC·폰 어디서나, 수익화 단계)

`render.yaml` 이 들어 있어 [Render](https://render.com) 에서 **New → Blueprint** 로 이 저장소를 고르면 바로 배포됩니다(데이터 보존용 디스크 포함). 다른 곳은 `Dockerfile` 을 사용하세요.

필수 환경변수: `ANTHROPIC_API_KEY`, `ADMIN_EMAILS`(관리자 이메일). 선택: `PAYMENT_URL`(결제·문의 링크), `PRICE_TEXT`, `TRIAL_DAYS`, `FREE_MONTHLY_LIMIT`.

배포 후 PC 에서는 `.env` 에 `APP_URL=https://내도메인` 을 적으면 바탕화면 아이콘이 내 PC 서버 대신 클라우드 주소를 앱 창으로 엽니다.

## 5. 수익화 운영

- 가입하면 **14일 무료 체험** → 끝나면 **무료(월 10회)** → **프로(월 9,900원)**.
- 처음에는 계좌이체·카카오톡으로 결제받고, 관리자가 **내 정보 → 관리자: 가입자·요금제 관리**에서 "프로 + 1개월"을 적용합니다(남은 기간 뒤로 연장).
- 온라인 결제(토스페이먼츠 등 정기결제) 연동은 다음 단계로, `PATCH /api/admin/users/:id` 와 같은 동작을 결제 완료 웹훅에서 호출하면 됩니다.
- AI 비용 감각: 기본 설정(`claude-opus-5-5`, effort `low`)에서 답글 1건당 입력 약 1.5천 토큰 + 출력 수백 토큰으로 대략 수십 원 수준입니다. 매장당 월 사용량과 요금을 비교해 `PRO_MONTHLY_LIMIT` 을 정하세요. 모델은 `ANTHROPIC_MODEL` 로 바꿀 수 있고, effort 를 지원하지 않는 모델이면 `ANTHROPIC_EFFORT=` 처럼 비워 두세요.
- 첫 단계는 아이디어 그대로입니다: 단골 가게 사장님 1~2명에게 무료로 써 보게 하고 "리뷰 답글에 하루 몇 분 쓰세요?"를 물어보세요. **리뷰함 → 아낀 시간(추정)** 이 대화 거리가 됩니다.

## 6. 모바일 앱으로 스토어 배포

`mobile/` 폴더에 [Capacitor](https://capacitorjs.com) 앱 껍데기가 있습니다. 자세한 절차는 [`mobile/README.md`](mobile/README.md) 를 보세요.
앱은 클라우드 서버 주소를 불러오는 방식이라 **기능 개선 시 스토어 재심사 없이** 서버 배포만으로 반영됩니다.

## 7. 구조

```
server/            API 서버 (Node 내장 http + 내장 SQLite, 외부 의존성은 Anthropic SDK 하나)
  index.js         라우트, 실시간 동기화(SSE), 웹앱 파일 제공
  ai.js            Claude 답글 생성 (실패 시 내장 엔진으로 자동 대체)
  templates.js     내장 문장 엔진 + 악성 리뷰 감지
  auth.js db.js config.js
public/            웹앱(PWA): index.html, app.js, styles.css, sw.js(자동 업데이트), 아이콘
scripts/
  launch.js        아이콘 더블클릭 진입점 (--install 아이콘 만들기, --stop 끄기)
  supervisor.js    서버 감시·재시작 (앱 안 업데이트 후 자동 재시작)
  updater.js       git / 매니페스트 방식 업데이터
launcher/          OS 별 실행 파일
mobile/            스토어 배포용 Capacitor 프로젝트
test/              API·AI 테스트 (npm test)
```

개발: `npm install` → `npm start` (http://localhost:8787) · 테스트: `npm test`
